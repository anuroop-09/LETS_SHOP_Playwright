# LETS_SHOP_Playwright

Automated browser testing for the Lets Shop demo application using JavaScript, Playwright Test, and the Page Object Model. The suite covers key shopping workflows such as registration, login, product browsing, cart and order management, and end-to-end purchases.

## Project Structure

```text
LETS_SHOP_Playwright/
├── src/
│   ├── fixtures/             # Shared test fixtures (currently empty)
│   ├── page-components/      # Reusable UI components, such as navigation and toast messages
│   ├── pages/                # Page objects for application screens
│   └── utils/                # Shared helpers for data, Excel, and common actions
├── testdata/
│   ├── excel/                # Spreadsheet-based test data
│   └── json/                 # JSON test data
├── tests/
│   ├── api_tests/            # API test location (currently empty)
│   ├── functional_tests/     # Registration, login, product, cart, order, and purchase tests
│   └── visual_tests/         # Visual test location (currently empty)
├── snapshots/                # Playwright snapshot location
├── package.json              # Dependencies and npm scripts
├── package-lock.json         # Locked dependency versions for repeatable installs
├── playwright.config.js      # Active Playwright configuration
├── playwright_config.js      # Alternate, separately selectable configuration
└── README.md
```

Playwright also creates `test-results/`, `playwright-report/`, and `allure-results/` when tests run. These are generated artifacts and are excluded from Git.

## Prerequisites

- Node.js (LTS recommended) and npm
- Google Chrome installed on the machine running the tests
- Network access to the configured test application

The active configuration launches the installed Google Chrome browser through Playwright's `chrome` channel. Installing Playwright's bundled Chromium alone does not satisfy this requirement.

## Download and Install

### Clone with Git

```bash
git clone <repository-url>
cd LETS_SHOP_Playwright
npm ci
```

Replace `<repository-url>` with the repository's clone URL. `npm ci` installs the exact dependency versions recorded in `package-lock.json`.

### Download as a ZIP

1. Open the repository page in your Git hosting service and select **Code** > **Download ZIP**.
2. Extract the ZIP archive.
3. Open a terminal in the extracted `LETS_SHOP_Playwright` folder.
4. Install dependencies:

```bash
npm ci
```

Do not download or copy `node_modules`; it is regenerated by the install command.

## Configuration

The active configuration loads environment variables from a `.env` file in the project root. The application URL defaults to `https://rahulshettyacademy.com`. To target another permitted test environment, create `.env` in the project root and set:

```dotenv
APP_URL=https://your-test-environment.example
```

Use the base URL only; tests navigate to application routes from it. Keep credentials and other secrets out of source control. The current automated tests also use the data files in `testdata/`; provide valid test accounts and data for the target environment where required.

## Run Tests

Run all discovered tests:

```bash
npm run suite
```

List tests without launching a browser:

```bash
npm run suite -- --list
```

Run one test file or filter by a test title:

```bash
npx playwright test tests/functional_tests/LoginTest.spec.js
npx playwright test --grep "Login Page Tests"
```

The active configuration is `playwright.config.js`. It discovers tests under `tests/`, runs them in parallel on Google Chrome, and retains traces, screenshots, and video for failed tests. Tests target the live application, so test runs require that site and its test data to be available.

The repository also includes `playwright_config.js`, which is not used by `npm run suite`. To explicitly run with that alternate configuration:

```bash
npx playwright test --config=playwright_config.js
```

## Reports

The Playwright HTML report is generated by the test run and can be opened with:

```bash
npm run report:html
```

The active reporter also writes Allure result files. Allure report generation and opening use the Allure command-line tool, which is not currently listed as a project dependency and must be installed separately:

```bash
npm run allure:generate
npm run report:allure
```

The `custom_cmd` script runs the tests, generates the Allure report, and opens it; it therefore also requires the Allure CLI to be available.

## Available npm Scripts

| Script | Purpose |
| --- | --- |
| `npm run suite` | Run the Playwright test suite |
| `npm run report:html` | Open the Playwright HTML report |
| `npm run allure:generate` | Generate an Allure report from `allure-results/` (requires the Allure CLI) |
| `npm run report:allure` | Open the generated Allure report (requires the Allure CLI) |
| `npm run custom_cmd` | Run tests, generate the Allure report, and open it |
